## Repository policy

**No new repositories are to be created for the projects listed here.** Keep existing codebases in their current repositories. Use this hub for cross-project planning, specifications, research, and the master index. Do not split every idea into another repository.

The index is based on project details available in retained ChatGPT context and recent discussions. It is a working portfolio map, not a complete export of every ChatGPT conversation or a guarantee that every planned feature is implemented.
